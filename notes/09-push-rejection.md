# 第 9 课 ： 推送拒绝

实验目标 - 如果两个本地仓库先后推送，后一个的推送是否会成功？

解释第一次推送为什么被拒，并说明历史分叉和文件内容冲突的区别。
 - 。分叉在 A 尝试推送之前就已经存在。A 和 B 从同一个起点各做了一笔提交，B 先推送，导致远程 main 有了 A 尚未包含的提交。合并后，B 的 d58328e 成为 0cd4f50 的第二个父提交，因此 GitHub 可以把远程 main 快进到 0cd4f50。

写出合并提交 0cd4f50 的两个父提交，并解释 GitHub 为什么可以接受合并后的推送。
- ec9bd4a；d58328e；合并后的推送的其中一个父提交就是B的 d58328e ，所以可以接受合并后的推送。而能否快进合并取决于提交之间的祖先关系，是否需要手动解决冲突取决于两边的内容能否自动合并。第 9 课已经分叉，所以需要三方合并，但两边改了不同文件，Git 可以自动合并。
